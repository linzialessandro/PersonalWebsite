# Data Layer Knowledge Base

Documentation of the static data modules that feed content into page components.

# Concepts

- [Publications Data](/data/publications-data.md) - 12 published papers, 3 preprints, and 1 submitted manuscript.
- [Teaching Data](/data/teaching-data.md) - Textbook, guides, and student resource lists.
- [Academic Network Data](/data/academic-net-data.md) - Collaborators and reference sites.
- [AI Gallery Data](/data/ai-gallery-data.md) - Imagined dialogues and two short verses.
- [CV Data](/data/cv-data.md) - Appointments, education, PDF path, and optional AI CV link.
