# Data Layer Knowledge Base

Documentation of the static data modules that feed content into page components.

# Concepts

- [Publications Data](/data/publications-data.md) - Static dataset of 12 published papers, 1 preprint, and 3 submitted manuscripts with DOI links.
- [Teaching Data](/data/teaching-data.md) - Static dataset defining 10 teaching resource sections with heterogeneous content types.
- [Academic Network Data](/data/academic-net-data.md) - Static dataset of 9 research collaborators and 5 academic community links.
- [AI Gallery Data](/data/ai-gallery-data.md) - Static dataset of 9 AI-generated mathematician dialogues (PDFs) and 2 mathematical poems.
- [CV Data](/data/cv-data.md) - Static dataset providing the CV PDF asset path and AI-powered interactive CV link.
