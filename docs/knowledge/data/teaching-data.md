# Teaching Data

Exports named lists and constants consumed by [Teaching Page](/pages/teaching.md). Narrative copy stays in the page; this module holds links and bibliographic facts.

| Export                   | Description                                                              |
| ------------------------ | ------------------------------------------------------------------------ |
| `teachingBook`           | Slovenian engineering textbook citation                                  |
| `firstTexUrl`            | LaTeX presentation PDF                                                   |
| `everydayResources`      | Wolfram Alpha, Mathematics Stack Exchange, OEIS                          |
| `latexGuides`            | Overleaf, English LaTeX learning links, and TeX Stack Exchange           |
| `italianLatexGuides`     | Pantieri texts                                                           |
| `learningResources`      | High-school and university study sources (Khan, YouMath, Lamar, MIT OCW) |
| `codingResources`        | Colab, SciPy Lectures, and SymPy documentation                           |
| `visualizationResources` | Desmos, GeoGebra, 3Blue1Brown, and Manim                                 |
| `competitionResources`   | Project Euler and AoPS                                                   |
| `teachingApps`           | Mate-matician, SenzaTesto, and AI literacy guide                         |
| `teachingNav`            | Top-level section anchors (`materials`, `projects`, `students`)          |
